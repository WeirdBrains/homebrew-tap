# WeirdBrains Homebrew tap

```sh
brew install weirdbrains/tap/muninn            # mnnn, the Muninn CLI and TUI (macOS, Linux)
brew install --cask weirdbrains/tap/muninn     # Muninn.app (macOS), from v2.20.1 on
```

[Muninn](https://muninn.weirdbrains.com) is a local, encrypted workbench for market data.
The formula and cask are generated from
[WeirdBrains/muninn](https://github.com/WeirdBrains/muninn) (`packaging/homebrew/`,
filled in by `scripts/fill-sums.py`) on each release.
